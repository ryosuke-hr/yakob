# カード画像

RevK の SVG トランプ（https://www.me.uk/cards/ 、ソース: https://codeberg.org/RevK/SVG-playing-cards ）。
CC0（パブリックドメイン）。クレジット表記は不要だが、作者への感謝としてここに記す。

生成時の設定: ポーカーサイズ / 4色（♠ 黒・♥ 赤・♦ 青・♣ 緑）/ Ignis（ドラゴン）ジョーカー / 裏面 Goodall / スペードのAの文字・QRコードなし

ファイル名: `{ランク}{マーク}.svg`。ランクは A, 2〜9, T(10), J, Q, K。マークは S, H, D, C。
ジョーカーは `1J.svg` / `2J.svg`、裏面は `1B.svg` / `2B.svg`。
